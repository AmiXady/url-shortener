# Юзкейсы


## Акторы

| Актор            | Кто это                                                          | Канал      |
|------------------|------------------------------------------------------------------|------------|
| **Пользователь** | Обычный человек, создаёт ссылки по одной                         | Сайт       |
| **Партнёр**      | Магазин или сервис рассылок, создаёт ссылки массово              | REST API   |
| **Создатель**    | Роль: пользователь или партнёр, который создал конкретную ссылку | Сайт / API |
| **Посетитель**   | Кто угодно в интернете, переходит по ссылке                      | Браузер    |
| **Робот**        | Мессенджеры, соцсети, почтовые антивирусы                        | HTTP       |
| **Система**      | Фоновые процессы сервиса (без участия человека)                  | —          |
