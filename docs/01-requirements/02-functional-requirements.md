# Функциональные требования

> Сервис сокращения ссылок `sho.rt`. Требования собраны на мок-собеседовании,
> подробный ход вопросов — в [interview.md](interview.md).

## Акторы

| Актор            | Описание                                                                    | Канал    |
|------------------|-----------------------------------------------------------------------------|----------|
| **Пользователь** | Создаёт ссылки по одной. Их большинство                                     | Сайт     |
| **Партнёр**      | Магазины и сервисы рассылок, создают ссылки массово                         | REST API |
| **Посетитель**   | Кто угодно в интернете, переходит по ссылкам. Без регистрации               | Браузер  |
| **Робот**        | Мессенджеры, соцсети, почтовые антивирусы. Заходят по ссылкам автоматически | HTTP     |

---

## FR-1. Создание ссылки

- **FR-1.1** Пользователь или партнёр отправляет длинный URL и получает короткую ссылку.
- **FR-1.2** Партнёр может создать **до 1000** ссылок одним запросом.
- **FR-1.3** Повторное сокращение того же URL всегда создаёт **новую** ссылку.
  Ссылки разных создателей полностью независимы.
- **FR-1.4** При создании можно указать **свой код** (см. FR-2.2).
- **FR-1.5** При создании можно указать **срок жизни**: количество дней или дату.
  Необязательно, по умолчанию ссылка бессрочная.

### Валидация

- **FR-1.6** URL должен быть корректным: схема `http` или `https`, есть домен.
- **FR-1.7** Невалидная одиночная ссылка → ошибка с понятным описанием причины.
- **FR-1.8** В пачке валидные ссылки создаются, невалидные — нет.
  Ответ содержит результат **по каждой** ссылке из запроса: короткую ссылку или причину ошибки.
  Молча пропускать невалидные нельзя.

## FR-2. Формат короткой ссылки

- **FR-2.0** Домен: `sho.rt`, формат: `https://sho.rt/{код}`.

### FR-2.1 Сгенерированный код

- Длина — **7 символов**.
- Алфавит — строчная латиница и цифры **без путающихся символов** (`0`, `o`, `1`, `l`, `i`).
- **Регистр не важен**: `sho.rt/ABC123` и `sho.rt/abc123` — одна и та же ссылка.

### FR-2.2 Свой код

- Длина от **3 до 30** символов.
- Алфавит: латиница, цифры, `-`, `_`.
- Код уже занят → ошибка, пользователь выбирает другой.
- Нельзя использовать зарезервированные служебные пути (например, `api`).


### FR-2.3 Повторное использование кода

- Пока запись об удалённой или истёкшей ссылке хранится (**1 год**, см. NFR-2),
  её код **занят**: создать новую ссылку с таким кодом нельзя.
  Иначе старые листовки и письма поведут на чужой сайт.
- После окончательного удаления записи (UC-8) код **освобождается** и может быть
  использован снова. Например, магазин каждый год занимает `sho.rt/black-friday`.
- Сгенерированные коды отдельно не резервируются: при ~27,5 млрд комбинаций
  повтор маловероятен.

## FR-3. Переход по ссылке

- **FR-3.1** Посетитель открывает короткую ссылку и сразу перенаправляется на оригинальный URL.
- **FR-3.2** Авторизация для перехода не нужна.

| Ситуация                   | Ответ                                 | HTTP-статус     |
|----------------------------|---------------------------------------|-----------------|
| Ссылка действует           | Редирект на оригинальный URL          | `302 Found`     |
| Ссылки никогда не было     | Страница «Ссылка не найдена»          | `404 Not Found` |
| Ссылка истекла или удалена | Страница «Ссылка больше не действует» | `410 Gone`      |

---

## FR-4. Статистика

- **FR-4.1** Создатель может посмотреть **общее число переходов** по своей ссылке.
  Разбивка по дням, странам и т. п. не нужна.
- **FR-4.2** Статистику видит **только создатель** ссылки. Регистрации при этом нет.
- **FR-4.3** Считаются переходы **реальных людей**: запросы известных роботов
  (мессенджеры, соцсети) не учитываются. Идеальная точность не требуется.

---

## FR-5. Управление ссылкой

- **FR-5.1** Создатель может **удалить** свою ссылку. После удаления редиректа нет, ответ `410`.
- **FR-5.2** Удалить ссылку может **только создатель**.
- **FR-5.3** Изменить оригинальный URL **нельзя** (защита от подмены на фишинговый сайт).
- **FR-5.4** Изменить срок жизни **нельзя**.

---

## FR-6. Срок жизни

- **FR-6.1** По умолчанию ссылка живёт бессрочно.
- **FR-6.2** Если указан срок, после его истечения редиректа нет, ответ `410`.

- Загрузка ссылок файлом (CSV) через сайт.
- Разбивка статистики по дням, странам, устройствам.
- Изменение созданной ссылки.
