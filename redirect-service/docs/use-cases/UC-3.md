## UC-3. Перейти по ссылке

**Актор:** Посетитель
**Требования:** FR-3, FR-6, NFR-3, NFR-4

**Основной сценарий:**

1. Посетитель открывает `https://sho.rt/{код}`.
2. Система приводит код к нижнему регистру и находит ссылку.
3. Система отвечает `302` с оригинальным URL.
4. Система фиксирует факт перехода (→ UC-7), **не задерживая** ответ.

**Альтернативные сценарии:**

- **2a. Код не найден** → страница «Ссылка не найдена», `404`.
- **2b. Ссылка удалена** → страница «Ссылка больше не действует», `410`.
- **2c. Срок жизни истёк** → страница «Ссылка больше не действует», `410`.
- **4a. Учёт перехода недоступен** → редирект всё равно выполняется (NFR-4.1).

**Результат:** посетитель на целевой странице, задержка с нашей стороны < 50 мс (p99).
