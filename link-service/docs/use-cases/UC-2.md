## UC-2. Создать пачку ссылок

**Актор:** Партнёр (API)
**Требования:** FR-1.2, FR-1.8

**Основной сценарий:**

1. Партнёр отправляет список до 1000 элементов, каждый — как в UC-1 (URL, свой код, срок жизни).
2. Система обрабатывает каждый элемент по сценарию UC-1.
3. Система возвращает результат **по каждому элементу** в том же порядке: короткую ссылку или причину ошибки.

**Альтернативные сценарии:**

- **1a. Больше 1000 элементов** → ошибка всего запроса.
- **1b. Пустой список** → ошибка всего запроса.
- **2a. Часть элементов невалидна** → валидные создаются, невалидные помечаются ошибкой. Запрос в целом успешен.

**Результат:** партнёр по ответу точно знает, какие ссылки созданы, а какие нет.
