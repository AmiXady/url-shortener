## UC-1. Создать ссылку

**Акторы:** Пользователь (сайт), Партнёр (API)
**Требования:** FR-1.1, FR-1.3–FR-1.7, FR-2

**Входные данные:**

- длинный URL — обязательно;
- свой код — необязательно;
- срок жизни (дни или дата) — необязательно.

**Основной сценарий:**

1. Актор отправляет длинный URL.
2. Система проверяет URL.
3. Система генерирует уникальный 7-символьный код.
4. Система сохраняет ссылку.
5. Система возвращает короткую ссылку `https://sho.rt/{код}` и данные для управления ссылкой (подтверждение, что актор —
   её создатель).

**Альтернативные сценарии:**

- **1a. Указан свой код** → система проверяет формат (3–30 символов, `a-z 0-9 - _`) и что код не зарезервирован; на шаге
  3 использует его вместо генерации.
- **1b. Указан срок жизни** → система сохраняет дату истечения.
- **2a. URL невалидный** → ошибка с понятным описанием причины.
- **3a. Свой код уже занят** → ошибка «код занят».
- **3b. Свой код зарезервирован** (например, `api`) → ошибка.
- **1c. Срок жизни в прошлом** → ошибка.
