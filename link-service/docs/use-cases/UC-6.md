## UC-6. Удалить ссылку

**Актор:** Создатель
**Требования:** FR-5.1, FR-5.2, NFR-5.2

**Основной сценарий:**

1. Создатель запрашивает удаление своей ссылки, предъявляя подтверждение.
2. Система проверяет, что запрос от создателя.
3. Система помечает ссылку удалённой (запись сохраняется для ответа `410`).

**Альтернативные сценарии:**

- **2a. Подтверждение неверное** → отказ в доступе.
- **2b. Ссылка не существует** → `404`.
- **3a. Ссылка уже удалена** → успешный ответ (повторное удаление ничего не меняет).

**Результат:** переходы по ссылке возвращают `410`. Несколько секунд ссылка ещё может открываться — это допустимо.
