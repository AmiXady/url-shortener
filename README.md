# URL Shortener

Сервис сокращения ссылок. Пет-проект для подготовки к собеседованию на Java Middle:
задача «спроектируй сервис сокращения ссылок», пройденная от требований до кода.

## Стек

- Java 21
- Spring Boot 3.5
- Maven

## Запуск

```bash
mvn spring-boot:run
```

Тесты:

```bash
mvn test
```

## План

1. **Требования** — уточнить функциональные и нефункциональные требования, оценить нагрузку.
2. **Архитектура** — API, модель данных, генерация кода, кэширование, статистика.
3. **Реализация** — написать сервис.
